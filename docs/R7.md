## 1. What changes and why

The app works, but it reads like a settings form: a 30 px trip name and stage pill on every tab, cards nested in cards, red Delete buttons as the loudest control on screen, ~15 font sizes, saturated category colors louder than the brand, and a logo built from an older palette than the UI. Round 7 is a **reshape for readability**, not new features — plus one small feature, a shared Google My Maps link (§8).

Principles, in order:
1. **One line of header.** The trip's name, dates and stage sit in the top bar on trip tabs; a big heading only where a page has nothing else to say (trips list, sign-in).
2. **Summary first, settings behind a tap.** Editable fields move into sheets opened from **Edit** or ⋯.
3. **Rows, not boxes in boxes.** A list is one card with divided rows. Cards never nest inside cards.
4. **Destructive actions live in ⋯ menus** (with the existing confirmation), never as a standing red button.
5. **Forest is the only action color; marigold only marks things** (chosen, cheapest, stale, the logo pin).
6. **The dotted path is the brand.** The logo's path reappears as the route ribbon, the walking-order line on Days, and step connectors.

## 8. Shared Google My Maps link (new)

**Why.** The group builds one shared Google My Maps map while exploring, then imports it to rank places and build days. Today the map's link lives in someone's messages. It belongs on the trip, and the import should start from it.

**Data.** `trips.myMapsUrl: string | null` — the link as the owner pasted it, after `safeUrl()`. New trips start with `null`; trips without the field read as `null`. Written with `updateTripFields(tripId, { myMapsUrl })`. Security rules don't change (any allowed user may update trip fields).

**Logic** (`js/lib/mymaps.js`, pure, tested):
- `parseMyMapsUrl(text)` → `{ mid, url, viewUrl, kmlUrl }` or `null`. Accepts `https://www.google.com/maps/d/<anything>?mid=<id>…` and `https://google.com/maps/d/…` (also `/u/0/edit`, `/viewer`, `/embed`). `mid` is `[A-Za-z0-9_-]{10,}`. `viewUrl` = `https://www.google.com/maps/d/viewer?mid=<mid>`; `kmlUrl` = `https://www.google.com/maps/d/kml?mid=<mid>&forcekml=1` (downloads the whole map as KML, which the existing importer reads).
- `isShortMapsLink(text)` → true for `maps.app.goo.gl/…` and `goo.gl/maps/…`: these can't be read without fetching (§2), so the field says "That's a short link. Open it, then copy the address from the browser bar and paste that."
- Anything else → "That doesn't look like a Google My Maps link (it should contain google.com/maps/d/)."
